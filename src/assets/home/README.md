# Home page media

Drop ski / snowboard **videos** (`.mp4`, `.webm`, `.mov`) or **photos** (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`)
into this folder. The home page picks one at random on every visit and plays it faded in the background.

Tips:
- Short muted loops (10–30 s, 1080p, a few MB) work best.
- Files here are git-ignored so large videos don't end up in the repo.
- Restart `npm run dev` if a newly added file doesn't show up.
